# BC_djs_bot 開發總表

更新日期：2026-08-20

這一份是**儀表板**，只放狀態與依賴。每個單元的目標、設計、檔案清單、進度與驗收都在它自己的檔案裡。
**開工時只讀 `CLAUDE.md` ＋ 你負責的那一個單元檔，不要讀這裡以外的其他單元。**

## 現在可以同時開的

- 一條 `U01 → U02`（兩者都改 `main.js` 與 `loader.js`，必須前後做）
- 一條 `U06`（全新檔案，與任何單元都不重疊）
- `U03` 完成後，`U04` 與 `U05` 可以再平行兩條
